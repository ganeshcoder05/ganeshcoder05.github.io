# Ganesh Verma, Portfolio

Personal portfolio of Ganesh Verma, a BTech Computer Science student learning full stack web development (React, Node.js, Express, MongoDB).

## Folder structure
```
index.html          the page
css/style.css       all styles (light and dark theme, layout, hover effects)
js/script.js        all behaviour (particles, ID badge, menu, theme, tabs, form)
assets/images/      photos, certificate images and video thumbnails
assets/videos/      short project demo clips
```

## Built with
- HTML, CSS and plain JavaScript, no framework and no build step
- [Three.js](https://threejs.org/) (loaded from a CDN) for the particle background
- Google Fonts: Bricolage Grotesque and Figtree

## Run it
Open `index.html` in any modern browser. An internet connection is needed for the fonts and Three.js.
