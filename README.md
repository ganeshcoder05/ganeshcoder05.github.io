## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

Replace `YOUR-REPOSITORY-NAME` with your actual GitHub repository name.

```bash
git clone https://github.com/ganeshcoder05/ganeshcoder05.github.io
```

### 2. Navigate to the project folder

```bash
cd ganeshcoder05.github.io
```

### 3. Open the website

Open `index.html` in any modern web browser, or use the Live Server extension in VS Code.

**Note:** An internet connection is required to load Three.js and Google Fonts from their CDNs.
